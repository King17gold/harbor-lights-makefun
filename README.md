# Harbor Lights

[![make.fun · best-game-01](https://make.fun/badge/best-game-01.svg)](https://make.fun/bounty/best-game-01)

An original browser game: steer a small boat through a dark harbor, collect lanterns, light the pier, and dock to clear each night. Avoid reefs. Built for make.fun's “Make the best game” bounty.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Controls: arrow keys or WASD. Enter / Space / click to start or restart.
